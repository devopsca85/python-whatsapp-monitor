═══════════════════════════════════════════════════════════════════════════════
                          🎯  KEY DECISION POINTS
═══════════════════════════════════════════════════════════════════════════════

    Decision: "Should I send an alert?"
    
    ┌────────────────────────────────────────────────────────────┐
    │                                                            │
    │  ❌ NO ALERT if:                                          │
    │     - First time discovering item (prev is None)          │
    │     - Status unchanged (prev == current)                  │
    │     - Status is "OK" and was always "OK"                  │
    │                                                            │
    │  ✅ SEND ALERT if:                                        │
    │     - Status changed (prev != current)                    │
    │     - Item deleted (was in prev, not in current)          │
    │     - Item recovered (was in deleted_set, now back)       │
    │     - Service went down                                   │
    │     - Service came back up                                │
    │                                                            │
    └────────────────────────────────────────────────────────────┘
